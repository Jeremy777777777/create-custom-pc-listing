# Product-generated photos

Final Amazon gallery images are organized by verified internal model under
`VL-<internal-model>/`.

Follow [the dedicated product-image workflow](../references/amazon-product-image-workflow.md)
and [the current image specification](../references/image-spec.md). Each product
folder contains `MAIN`, `PT01`–`PT08`, and an `image-manifest.md` production
record. Image work is separate from the listing workbook.

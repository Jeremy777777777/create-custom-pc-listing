# Image style profiles

Additional profiles: `mini-pc-real-game-editorial-v1` = M04/MG04; `gaming-real-game-editorial-v1` = G22/A22/GG22. Follow their complete original-media workflow and `assets/mini-gaming-style-policy.json`. These are proposal routes, not accepted production locks.

Verified standalone Mini PCs first use the independent [M/MG design system](mini-pc-design-system.md), with M04/MG04 for gaming-focused proposals and M01/MG01, M02/MG02 or M03/MG03 as general-purpose/other alternatives. Keep audience separate; Windows Pro does not automatically select Business. The families are available choices, not approved product styles.

For new Gaming proposals, use [original-media gaming editorial design](mini-gaming-real-source-workflow.md): G22/A22/GG22 is the default proposal, with genuine game artwork and original logos, a dominant accurate product and grouped nonrepetitive information. G17–G21 remain [natural alternatives](gaming-natural-design.md). This 2026-10-29 user decision changes proposal routing, not existing product approvals, MAIN boundaries, accessory treatment or factual/visual QA.

Profiles affect palette/type/visual hierarchy, not [catalog policy](confirmed-catalog-defaults.md), accurate hardware, fixed slots or Windows identities. MAIN-STRICT remains white and unadorned. Both enhanced candidates share a family with task-adapted LCD composition. Business uses distinct lockup/package; others package/package. Desktop/AIO full-product views include keyboard and mouse using the [catalog accessory treatment](confirmed-catalog-defaults.md); no other external-device imagery or outside-LCD MAIN information.

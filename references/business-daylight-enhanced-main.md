## 制作流程

1. **先看当前整组图。** 读取当前事实、style-lock 与图片；实际查看整组缩略图及至少两张代表图，记录字色、光线、字体、留白和品牌位置。借鉴竞品的信息层级、场景及图标作用，不照搬其型号、参数、配件或整张图。
2. **准备真实产品和已确认信息。** 优先使用准确型号原始正面机身。测量真实屏幕内沿，保留边框、摄像头、键盘、掌托和机身标识。缺少来源时按 faithful-product-reproduction.md 的既有许可忠实复现并逐项检查，不生成未经证实的硬件。只补齐图片必需的缺失事实。
3. **单独生成照片。** 内置 image_gen 生成日光办公建筑／玻璃中庭照片，以当前附图为风格参考。左侧留浅灰自然墙面给深蓝文字，右侧是有空间感的玻璃建筑与蓝天。不要让模型同时重画最终机身、品牌和规格文字。
4. **分层排版。** 真实机身、照片、可编辑文字／通用功能图标、原始品牌分别保存。外部纯白、完整电脑足够大；新增信息仅在真实 LCD 内。型号最醒目，接着具体屏幕卖点，再是功能图标、CPU 身份、内存和 SSD 选择。保留照片，不做一屏同样大小的参数卡。
5. **检查实际图片。** 原尺寸核对文字、机身、品牌和边界；约 400px 看主要参数与选项；200px 看型号、轮廓和阅读主次。细小说明允许放大，不把“200px 每个字都可读”设成迫使画面退化的要求。真实清晰度问题仍需重排，不能虚报全字可读。
6. **保存和复现。** 保存自包含 SVG 或完整素材、提示词、原始品牌及透明衍生记录、坐标、事实来源和最终哈希。用冻结输入重渲染核对结果，不重新生成已认可的照片／整图。用户明确要求替换后，归档旧图和关联记录，在原 Drive ID 上替换请求图片，核对字节和父文件夹，同步当前说明与复核记录。

检查只证明自身范围，不自动给予其它产品风格认可，也不把单张替换说成整组重新通过。

## 设计规则

### 以照片和信息共同构图

采用当前产品风格，不强制夜景、金色摩天楼、抽象工作流或软件面板。照片应有空间、材质、光线与主体；文字落在自然留白。海军蓝文字配浅灰墙面，蓝色线性图标靠近对应功能。Intel 原始标识靠近 CPU 型号，Windows 原始身份靠近系统信息。

允许屏幕底部使用与配色一致的轻渐变，帮助白色原始 Windows 标识和容量选择阅读。这是照片与信息的过渡，不是占据大半屏幕的黑色参数板。旧的“连续背景”不再禁止本图这种渐变；品牌下面也不留占位块、旧徽章或重复标识。

MAIN 不要求机身外再贴一枚 OEM Logo；保留真实机身标识，型号文字识别产品。PT 的 OEM 角标要求独立保留。角度主图仍从真实 LCD 独立适配，不因本次正面修改自动重绘或替换。

### Customization 明确可解释

SSD 写为 SSD OPTIONS：512GB / 1TB / 2TB / 4TB。这是四种可选容量，不是同时安装，不按平台最大值筛掉用户确认选项。

RAM 先研究能否更换及确切 DDR／LPDDR 家族和版本：
- 不能更换：实际容量加实际类型，例如 VL-1223 的 32GB LPDDR5X，可加 Fixed memory，不画四档 RAM。
- 可以更换：8GB / 16GB / 32GB / 64GB，配研究确认类型；必要时重排，不缩成密集小字。
- 研究实际可更换性，不用 LPDDR 名称的简单推断代替研究，也不按平台上限筛选四档。

主图给简明选项；PT05 继续解释每档用途；PT03 是实际基础 CPU／GPU／RAM／SSD／OS 的完整配置页。数字属性保持实际基础配置。

### 原始 Logo 与透明处理

使用真实适用品牌。允许从已认可的原始 Windows 11 Pro 锁定图确定性裁切并提取原本白色图案的透明度，融入当前照片。保留原图、原 RGB、完整标志及 Windows 11 Pro 字样、方法和衍生哈希；实际核对边缘与完整性。优先复用本次冻结衍生，不反复提取或让 AI 重绘。

该已记录的有色底锁定图 alpha 提取，取代一律禁止“非中性背景移除”的旧解释；不允许擦除笔画、改色、重打字、改数字或拉伸。通用 remove-bg 工具仍只处理安全中性背景。

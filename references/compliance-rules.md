# Custom PC compliance checklist

Seller decisions are in [confirmed-catalog-defaults.md](confirmed-catalog-defaults.md); this file does not override them. Channel requirements must be verified for the actual account/category before publication. A competitor's listing never proves an exception. Historical source quotations/examples are archived and are not runtime prompts.

## Listing checks

Before workbook-based marketplace export or saved publication, run the mandatory [scoped export evidence check](research-ledger-projection.md). Require the exact target IDs, current workbook/ledger hashes and a successful export-mode result; draft-mode/structure PASS cannot substitute. This gate checks recorded evidence and does not replace factual or marketplace eligibility review.

- Exact `MegaPC Custom` title prefix, OEM model identified via Created Using, accurate base RAM/SSD only, Win 11 Pro ending, appropriate title length.
- Bullet 1, Description's final Warranty and Disclosure section and Warranty Description use the identical mandatory OEM/MegaPC wording, with verified OEM brand substituted. Seller policy is already confirmed; do not reopen coverage or invent terms.
- Actual RAM/storage modification disclosure is accurate; all computers are customized. No invented upgrade options, CPU/GPU/screen customization or software bundle. Fixed Windows 11 Pro is the sold system, not a selectable software customization.
- Exact SKU facts and evidence are consistent. Complete template coverage includes unresolved seller fields explicitly, not guessed values.
- Check program enrollment, required customization documentation, MFN/FBA eligibility, GTIN/new ASIN requirements and channel rules against current applicable account guidance. Any actual policy restriction is recorded in `AMAZON_ELIGIBILITY`; user policy does not constitute Amazon approval. Do not require an extra user approval merely to research/write the confirmed configuration.
- Original copy and properly licensed assets; competitor wording/artwork/UI/reviews are not reused.

## Image checks

Apply [image-spec.md](image-spec.md): Amazon-based size policy, computer only, no accessories/peripheral context, real model geometry, authentic factory marks preserved and fixed Windows identities. Product subjects may use authorized original photos or AI faithful reproductions of the official original machine that pass [faithful-product-reproduction.md](faithful-product-reproduction.md). Every depicted model, chassis, color, keyboard and visible connector must match the reference-supported actual machine; mismatched or unverified details cannot pass. Final brand logos and specification text continue to use approved assets and deterministic composition. This wording implements the user-approved replacement of the original-assets-only ambiguity on 2026-10-07. PT01–PT08 use deterministic transparent OEM logos with catalog visibility/spacing rules and schema 3 evidence. Full-gallery/current-hash evidence must pass; a manifest assertion alone is insufficient.

MAIN-STRICT is the default white-background computer image with no added graphics/text. Enhanced MAIN images are complete candidates; do not label them Amazon-approved or replace the channel's default MAIN without current exception evidence. Visual completion, remote upload and channel eligibility are separate.

## Source verification

For FCC equipment authorization research, follow [fcc-research-workflow.md](fcc-research-workflow.md), including ERP serial-first OEM configuration/part lookup and ranked candidate delivery. Distinguish host SDoC/certification from actual installed transmitter grants; keep evidence scope and responsible-party details tied to the sold configuration. Evidence-linked most-likely candidates may be delivered as INPUT_UNVERIFIED research recommendations with missing links stated; marketplace export uses only applicable VERIFIED IDs. Unresolved applicable FCC fields remain explicit compliance gaps, not assumed approval or a reason to fabricate an ID.

Use current official Amazon/account guidance for publication decisions and official component/OEM sources for product facts. OEM Windows Home and platform capacity limits do not override confirmed sold Pro/base capacities. New genuine external policy conflicts should be explained specifically, not hidden by reverting to archived seller rules.

The confirmed warranty wording requires no additional approval/source citation for review outputs. OEM applicability is a seller manual publication check, not a research/copy-production blocker. For standalone desktop enhanced candidates apply the DESKTOP_GRAPHIC_SAFE_ZONE exception in catalog policy; never imply Amazon acceptance.

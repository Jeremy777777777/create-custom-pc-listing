# Faithful reproduction of the official original computer — 2026-10-06

Apply the approved decision in [confirmed-catalog-defaults.md](confirmed-catalog-defaults.md). The user confirmed commercial authorization and explicitly approved replacing the three conflicting product-generation restrictions. This rule applies to every MAIN and PT slot, including Gaming, input details and physical port views.

## Production method

Use original authorized exact-model photographs directly or use AI to faithfully reproduce the official original machine from those photographs. Supply the official images as visual references. The target is the actual manufactured computer of the exact model, generation, region/layout, form factor and color, matched to the sold unit; a similar-looking computer is insufficient. Do not redesign, reinterpret, alter hardware for appearance, mix models or generate a product from text alone. Seller-confirmed RAM/SSD/OS changes follow the verified sold-configuration record and do not permit altering factory exterior hardware.

Acquire enough official visual evidence for every visible surface and detail before generation. Model specifications can corroborate a reference but cannot substitute for an unseen keyboard or connector layout. Missing view/detail evidence blocks the affected slot, not unrelated work. Never generate plausible unseen hardware.

## Hard fidelity acceptance gate

Compare the candidate against the official reference views at full size, using closeups for fine details and perspective-aligned comparisons where feasible. Inspect:

- silhouette, proportions, thickness, display bezels, hinges, stand/feet and panel shapes;
- chassis color/material/finish, vents, screws and visible surface details;
- exact keyboard layout, key count/shape/legends, regional layout, touchpad and controls;
- every visible connector's type, count, location and orientation;
- authentic factory marks and the same physical appearance across all slots.

Log each inspected category, reference path/hash, candidate hash and observed differences in the image manifest and current-hash manual-review notes. Mark non-visible categories NOT_VISIBLE with a reason; lack of evidence for a visible detail is UNVERIFIED, never PASS. Do not invent a similarity percentage or claim pixel identity as proof of hardware correctness. AI generation itself cannot guarantee fidelity.

A verified hardware mismatch requires REWORK_REQUIRED. An unverified visible detail requires sourcing or SOURCE_REQUIRED. Neither state may pass the slot or gallery. Correct the affected layer; if faithful AI reproduction cannot be achieved or confidently checked, use the authorized original photograph for that view. Do not deliver an unchecked approximation as final. Generation permission does not establish Amazon MAIN eligibility; publication review remains separate.

## Brands, text and repeatable composition

Final OEM/Windows/other brand artwork and specification text use approved original assets and deterministic composition. Do not approximate brand artwork with AI. Preserve authentic factory marks; if generation damages a mark, restore its accurate artwork, position, scale and perspective from official evidence. This is restoration of an existing physical mark, not an added MAIN marketing overlay. Lack of reliable restoration blocks that output or requires the original photograph.

Record reference sources, URL/date/model/color, USER_CONFIRMED_CATALOG_WIDE authorization, source hashes, generation prompt/record, generated product-master hash and masks. Keep source references and generated layers distinctly identified. After actual fidelity review, freeze accepted layers/masks and build the final composition with deterministic logos/text. The same saved layers can be reused; rerunning AI is not a reproducibility guarantee. Edits invalidate affected hash-bound evidence.

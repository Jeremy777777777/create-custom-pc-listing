# VA-215 B01/BG01 production pack

Official-original hardware layers + built-in imagegen art plates + deterministic text/branding. Rebuild with the dedicated listing-testing interpreter:

`python assets/production/VA-215/b01-20261020/build-gallery.py`

Rebuilding prepares files and invalidates acceptance. Inspect new current bytes and supply fresh review evidence; never rerun a saved review writer to claim a new manual PASS. A frozen approved style is not approval of unreviewed regenerated bytes. The build requires Pillow and Arial fonts on Windows; no NumPy or new package installation is needed. Source references are preserved in sources/, recipe.json and source-rights.json.
